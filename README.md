# Diplom_3
Проект содержит автоматизированные UI-тесты для веб-приложения Stellar Burgers. Тесты написаны на Python + Selenium + Pytest с использованием Allure для отчётности.

test_main_functionality.py - файл содержит тесты на проверку работы основной функциональности: проверка навигации и работы конструктора:

1) test_go_to_constructor -	проверяет переход по клику на «Конструктор»	После клика по кнопке «Конструктор» происходит возврат на главную страницу (URL меняется с /feed на корень, конструктор отображается).
2)	test_go_to_order_feed- проверяет переход по клику на «Лента заказов»	Клик по кнопке «Лента заказов» приводит к переходу на страницу с feed в URL.
3)	test_open_ingredient_modal - проверяет, что Клик по ингредиенту открывает модальное окно	При клике на ингредиент (булка из Data.BUN) открывается модальное окно с деталями.
4)	test_close_ingredient_modal - проверяет, что модальное окно закрывается по крестику	После открытия модального окна клик по крестику закрывает его (окно больше не отображается).
5)	test_ingredient_counter_increases - проверяет, что счётчик ингредиента увеличивается при перетаскивании в заказ	При перетаскивании булки в конструктор заказа счётчик ингредиента увеличивается (становится равен 2).

test_order_feed.py - файл содержит тесты на проверку Ленты заказов: проверка счётчиков и статусов заказов:
1) test_total_counter_increases - проверяет, что после оформления заказа увеличивается счётчик «Выполнено за всё время»
2) test_today_counter_increases - проверяет, что после оформления заказа увеличивается счётчик «Выполнено за сегодня»
3) test_new_order_is_in_progress - проверяет, что номер нового заказа появляется в разделе «В работе»
